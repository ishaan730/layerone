# Landing page prototype v2

An isolated prototype of a redesigned Layer One home page. **Nothing in production uses these files.**

- `layer-one-landing-v2.html`: the whole page in one file. Open it directly.
- `index.html`, `styles.css`, `app.js`: the source. Preview with `python3 tools/serve.py 8765`, then open
  `http://localhost:8765/prototype/landing-v2/index.html`.
- `build_standalone.py`: rebuilds the single file after editing the source.
- `REDESIGN.md`: the audit, strategy and rationale.
