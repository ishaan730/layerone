questions:

How long does it take to build a design system?

The foundations and first 12 components take six weeks in our Foundations engagement. Larger component sets, more brands or a migration of existing products take longer and are quoted separately.

Do you build the code as well as Figma?

We map every component one-to-one to code and pair with your engineers on the token pipeline and component APIs. For larger builds in React or web components we quote a component pack.

Which tools do you use?

Your tools: Figma variables and libraries, your repository, Style Dictionary or a similar token build, and Storybook if you have it. Tokens are stored in the vendor-neutral DTCG format.

How much does design system development cost?

Foundations is $5,900 fixed for six weeks: 50% to start, 50% on handover. Extra themes are $900 each and extra component packs $1,500 per six components.
