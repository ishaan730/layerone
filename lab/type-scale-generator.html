How to use it

  1. Choose a base and ratio

    16px with 1.2 suits most product UI; larger ratios suit marketing and editorial pages.

  2. Tune lines and rounding

    Keep sizes on whole pixels and line heights on even numbers, so design and code match.

  3. Go fluid if you need to

    Set a smaller base and ratio for phones; the export becomes clamp() values between the two screens.

Choosing a ratio

RatioFeels likeGood for

1.333 · Perfect fourthExpressiveMarketing sites, editorial
1.5 and upDramaticLanding pages with few levels

A ratio is a starting point, not a law. Most teams round the results and adjust one or two sizes by eye. What matters is that the sizes are named, shared and used everywhere.

Fluid sizes with clamp()

Fluid type lets headings grow smoothly between a small and a large screen instead of jumping at breakpoints. Each size becomes clamp(min, preferred, max): a minimum for phones, a maximum for large screens, and a preferred value in rem + vw between them. Using rem in the middle keeps text responsive to the reader's font-size setting.

One caution: if the largest size is more than about 2.5 times the smallest, browser zoom may not be able to double the text, which WCAG 1.4.4 asks for. The scale flags those sizes with “zoom”.

Questions

What is a modular type scale?

A set of font sizes where each size is the previous one multiplied by the same ratio, like 1.25. It gives a consistent rhythm between body text and headings.

What base font size should I use?

16px for most product UI, since it's the browser default and readable on every screen. 14px can suit dense tools; 18px suits reading-heavy sites.

How do I make fluid typography with clamp()?

Turn on fluid sizes, set the base and ratio for small screens and the screen widths to grow between. The CSS export gives a clamp() value for every size.

Should line height be unitless?

For fluid sizes, yes: the export uses unitless line heights so they scale with the text. Fixed scales export line heights on an even pixel grid.

Can I use it with Tailwind?

Yes. The Tailwind export gives a fontSize object with sizes, line heights and letter spacing.
