Which format should I use?

FormatUse it when
CSS custom propertiesYou want tokens available in any stylesheet or framework, and themeable at runtime.
TailwindYour product uses Tailwind and you want the tokens as utility classes.
SCSSYour codebase uses Sass and compiles values at build time.
DTCG JSONYou run a token pipeline (Style Dictionary, Tokens Studio, a Figma variables plugin). This is the vendor-neutral format from the W3C Design Tokens Community Group.

Primitive tokens first

The file contains primitive tokens: the raw palette, sizes and steps. The next step in a design system is a layer of semantic tokens that name a job (color-text-muted, space-inset-card) and point at primitives. Product code uses the semantic layer, so themes and rebrands only change the mapping.

Questions

What is a design token file?

A file of named design decisions (colours, sizes, spacing) that code and design tools read from, so values are defined once and used everywhere.

What is the DTCG format?

The JSON format from the W3C Design Tokens Community Group. Tools like Style Dictionary and Tokens Studio read it, and plugins can turn it into Figma variables.

Can I import tokens into Figma?

Export DTCG JSON and use a Figma variables or tokens plugin that reads the format.

Does the export include semantic tokens?

No. It exports primitives. Map them to semantic tokens that name each job; see our guide to design tokens.
